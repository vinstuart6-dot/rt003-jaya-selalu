CATATAN KEAMANAN:
Versi ini adalah aplikasi front-end gratis/offline/static. Login dan data pengelolaan disimpan di browser (localStorage), sehingga cocok untuk demo/prototipe atau penggunaan satu perangkat, bukan untuk data warga sensitif di internet.

Untuk versi publik yang aman dengan akun admin sungguhan dan database, hubungkan project ke layanan hosting/database yang mendukung authentication. Jangan menaruh password admin di kode frontend.

Cara menjalankan:
1. Buka index.html di browser, atau upload seluruh folder ke static hosting gratis.
2. Login menggunakan akun di atas.
3. Data yang ditambah dari dashboard tersimpan di browser perangkat tersebut.
